Project Overview
You're building a website for a high-end auto repair company that offers more than just repairs—think premium services like custom modifications, performance tuning, detailing, restoration, and perhaps concierge services. The site will use Next.js (with React) in JavaScript only (no TypeScript). We'll leverage Next.js's app router for modern routing and server-side capabilities.
The core features include:

Public pages: Home, Services, About, Contact (with form).
Additional pages: Blog (for tips/articles), Gallery (showcasing work), Testimonials.
Contact form: Submits data to an S3 bucket as a text file (e.g., .txt for human-readable format).
Admin dashboard: Protected page to list and view contact submissions pulled from S3, displayed in a readable format (e.g., formatted text or tables, not raw JSON).
AI Assistant: Integrate Claude (Anthropic API) as a chat widget for user queries (e.g., "What services do you offer for luxury cars?"). API key stored in .env.
Security: Admin credentials and API keys in .env; use environment variables for AWS S3 access.

This plan assumes you have an AWS account for S3 and an Anthropic account for Claude API. We'll use AWS SDK for Node.js to handle S3 interactions via Next.js API routes.

API Route for S3 Upload (/app/api/submit-contact/route.js):
Server-side: Convert form data to human-readable text (e.g., "Name: John\nEmail: john@example.com\n...").
Upload as .txt file to S3 with unique filename (e.g., contact-${Date.now()}.txt).JavaScriptimport { S3Client, PutObjectCommand } from '@aws-sdk/client-s3';

const s3 = new S3Client({
  region: process.env.AWS_REGION,
  credentials: { accessKeyId: process.env.AWS_ACCESS_KEY_ID, secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY },
});

export async function POST(req) {
  const data = await req.json();
  const readableContent = `Name: ${data.name}\nEmail: ${data.email}\nPhone: ${data.phone}\nService: ${data.service}\nMessage: ${data.message}`;
  
  const params = {
    Bucket: process.env.AWS_S3_BUCKET_NAME,
    Key: `contacts/contact-${Date.now()}.txt`,
    Body: readableContent,
    ContentType: 'text/plain',
  };

  try {
    await s3.send(new PutObjectCommand(params));
    return new Response('Uploaded', { status: 200 });
  } catch (err) {
    return new Response('Error', { status: 500 });
  }
}


Step 4: Admin Dashboard

Protected Route (/app/admin/page.js):
Client-side auth: Form for username/password, check against .env (hash password with bcryptjs for security).

Once logged in: Fetch list of S3 files, display in table.
For each file: Button to view content (fetch from S3 via API route).

API Route for S3 Fetch (/app/api/admin-contacts/route.js):
List objects: Use ListObjectsV2Command to get .txt files.
Get object: Use GetObjectCommand to read content as string (already human-readable).JavaScriptimport { S3Client, ListObjectsV2Command, GetObjectCommand } from '@aws-sdk/client-s3';
// Similar s3 setup as above...

export async function GET(req) {
  const { searchParams } = new URL(req.url);
  const action = searchParams.get('action');
  
  if (action === 'list') {
    const params = { Bucket: process.env.AWS_S3_BUCKET_NAME, Prefix: 'contacts/' };
    const data = await s3.send(new ListObjectsV2Command(params));
    return Response.json(data.Contents.map(obj => obj.Key));
  } else if (action === 'get') {
    const key = searchParams.get('key');
    const params = { Bucket: process.env.AWS_S3_BUCKET_NAME, Key: key };
    const data = await s3.send(new GetObjectCommand(params));
    const body = await data.Body.transformToString();
    return Response.json({ content: body });
  }
}
In admin page: Use fetch('/api/admin-contacts?action=list') to get list, then fetch individual contents.

Security Note: In production, add proper auth middleware (e.g., NextAuth.js) instead of simple env checks.

Step 5: Claude AI Assistant Integration

Chat Widget:
Create /components/AIAssistant.js: Floating chat bubble on all pages (via layout.js).
Use state for messages.
On user input: Send to Next.js API route (/app/api/claude/route.js) which calls Anthropic API.

API Route for Claude (/app/api/claude/route.js):JavaScriptimport { Anthropic } from '@anthropic-ai/sdk';

const anthropic = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY });

export async function POST(req) {
  const { message } = await req.json();
  try {
    const response = await anthropic.messages.create({
      model: 'claude-3-opus-20240229',  // Or your preferred model
      max_tokens: 1000,
      messages: [{ role: 'user', content: message }],
    });
    return Response.json({ reply: response.content[0].text });
  } catch (err) {
    return new Response('Error', { status: 500 });
  }
}
Usage: Prompt Claude with context like "You are an assistant for a high-end auto repair company specializing in luxury services."
